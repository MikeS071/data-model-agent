# Delivery

Apply [standing autonomy, persistence and candid judgment](../../policy.md#intent-autonomy-and-continuity). Routine scoped actions need no redundant permission round; stronger destination policy and protected-action gates remain.

Start with [session initialisation](../session-initialisation/SKILL.md). Match issue/PR templates and the validated delivery adapter. Use `tools/governance action plan --scope FILE --request FILE --delivery .governance/delivery.json`, review the original request and fresh plan, then explicit `action apply` with the same flags plus `--plan FILE` only within already verified authority. Keep ignored plans/receipts in `.governance-artifacts/`. Read exact external targets back; uncertain outcomes require reconciliation, not blind retries. The CLI has no merge or provisioning action.

One small issue maps to one reviewable PR. Review code at every size against root policy, [quality conditions](../../quality.md) and applicable full principle leaves. A feature above 400 changed lines needs decomposition or documented justification; retain total and category counts. Record rework against originating features only when evidence supports that link.

Implement first, then minimum essential [scope proof](../verification/SKILL.md); required project CI remains. Independently assess every criterion and complete intent. Preserve normal issue/parent/queue reconciliation. Stop before every merge for exact PR/target approval; production, providers, credentials and destructive operations retain separate authority. No skill/config/hash is approval.
