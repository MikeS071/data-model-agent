# Context handoff

At a meaningful transition, update the task's existing handoff location with the objective, accepted scope, current source, completed evidence, open gaps, running process or ownership state, and next action. Include paths to artifacts rather than copying large outputs. Note rejected approaches when their failure reason would prevent repeat work.

Keep credentials and sensitive data out of handoffs. Do not create a competing tracker or change global agent settings. Refresh external state that can drift before a consequential action; a new session alone does not invalidate sound acceptance evidence.
